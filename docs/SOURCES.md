API: `https://hadeethenc.com/api/v1/hadeeths/one/?language=sw&id={id}`.

`hadeeth_ar` na `hadeeth` zimehifadhiwa bila kuhariri. Response nzima imehifadhiwa katika `database/data/sources/`, ikiwemo maelezo na metadata ya chanzo. UI inaonyesha hadith yenyewe, daraja linalotajwa na chanzo na attribution. Kadi za matokeo zina preview inayofupishwa kwa CSS pekee; ukurasa wa hadith una maandishi yote.

Ulinganisho ni wa kiufundi: kulinganisha hadith na rejea yake. Hauwakilishi uhakiki mpya wa kielimu wala idhini binafsi ya mwanazuoni. Chanzo hakijataja jina la mtafsiri binafsi kwenye API. Hadith zinazopatikana katika makusanyo yote mawili zimewekwa mara moja chini ya rejea iliyochaguliwa.

Ruhusa ya mchapishaji: [IslamHouse / HadeethEnc official API hub](https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub). Inaruhusu kupakua, kuhifadhi na kuchapisha kwenye apps kwa kuhifadhi maandishi, kutaja chanzo na kusasisha nakala pindi chanzo kinaposasishwa. Hii si madai kwamba tafsiri ni public domain au kwamba leseni ya MIT ya code inatumika kwa maandishi.

Kumbuka kwamba namba ya mlango si sawa na namba ya hadith ndani ya kitabu. Kwa Muslim, app inaonyesha namba kuu ya HadeethEnc (55, 1907, 2553); link ya Sunnah.com ina suffix ya riwaya (`a`). Majina ya vitabu/milango ya Kiswahili ni lebo za urambazaji za app.
